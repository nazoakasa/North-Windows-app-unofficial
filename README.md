# North Client (v0.6 / C)

north.rip 用の Windows ネイティブクライアント。C + Win32 + GDI/GDI+ + WinHTTP。
画面は Web / モバイル版に寄せた Twitter ライクなダークテーマ。
ログインだけ WebView2 で行い(Cloudflare Turnstile を人間が通す)、それ以外は自前で API を叩く。

## 動かし方
1. `bin\north.exe` を起動 (`bin\WebView2Loader.dll` が同じフォルダにあること)
2. 初回はログイン窓が開くので north.rip にログイン → `/home` に入ると自動で閉じる

必要なもの: Windows 10/11 x64、Microsoft Edge WebView2 Runtime (Win11 は標準)

## 画面
ウィンドウ幅で自動的にレイアウトが変わる。
| 幅 | レイアウト |
|---|---|
| 約1060px以上 | 3カラム (左ナビ / タイムライン / 右サイド: トレンド・おすすめ) |
| 約700px以上 | 2カラム (アイコンだけの左ナビ / タイムライン) |
| それ未満 | スマホ風 (上部バー + 下タブ + 右下の投稿ボタン + 左からのドロワー) |

実装済み:
- ホーム: ポスト入力 / 返信 / 無限スクロール / 新着バナー
- プロフィール: ヘッダー・自己紹介・4タブ・**フォロー / フォロー解除**・**DM を送る**ボタン
- **通知**: すべて / メンション、未読の強調、まとめ表示 (「◯◯さん、他N人が…」)、返信・引用は投稿カードで表示、開くと既読にする
- **検索**: 入力中のサジェスト (ユーザー・ハッシュタグ)、検索履歴 (削除可)、トップ / 最新 / ユーザー / メディアの4タブ、トレンド
- **メッセージ (DM)**: 会話一覧 (未読バッジ・グループ)、メッセージリクエスト、チャット (自分/相手の吹き出し・画像・リンク)、
  送信 (`Enter`、改行は `Shift+Enter`)、既読化、入力中の表示と送信、4秒ごとの自動更新、過去分の読み込み
- **スレッド**: ポスト本文(または引用)をクリックで開く。親ポスト・主ポスト・返信を表示し、下の入力欄から返信できる (`Ctrl+Enter` か送信ボタン)
- **ポスト入力の機能**: アンケート作成 (選択肢2〜4・期間指定)、太字/斜体 (`B` `I` ボタン / `Ctrl+B` `Ctrl+I`、`<太字>…</太字>` `<斜体>…</斜体>` `<色=赤>…</色>` のタグを挿入)、
  返信できる人の制限 (全員 / フォロー中 / @した人)、文字数カウンター、絵文字パネル (Win+.)
  表示側も書式タグ(太字・斜体・色)とアンケート(投票・結果バー・残り時間)に対応
- **自分のポスト**の「…」メニュー: プロフィールに固定 / 返信制限の変更 / 削除
- **画像ビューア**: ポスト・DM の画像、プロフィールのアイコン/ヘッダー、添付のプレビューをクリックすると、ブラウザではなくアプリ内で全画面表示する。
  ホイールで拡大 (カーソル位置を中心に)・ドラッグで移動・ダブルクリックで等倍/拡大の切り替え、複数枚は `←` `→` か左右のボタンで切り替え、`Esc` / ×ボタン / 背景クリックで閉じる。
  右上のボタンで「ブラウザで開く」もできる。動画と GIF はこれまでどおりブラウザで開く
- **画像添付**: ポスト入力・スレッド返信・DM で、画像ボタン(ファイル選択)かウィンドウへのドラッグ&ドロップで最大4枚 (png / jpg / gif / webp、50MBまで)。
  プレビュー付き、アップロード中・失敗の表示、×で外せる。画像だけのポストも可
- **ブックマーク一覧**: 左ナビ / ドロワーの「ブックマーク」。無限スクロール
- いいね / リポスト / ブックマーク / リンクコピー ・ 画像(1〜4枚) ・ リンクカード ・ 引用 ・ 未読バッジ ・ トレンド
未実装 (押すとブラウザで開く): リスト・設定・プロフィール編集。
未実装 (機能なし): ブックマークのフォルダ分け。
未実装 (機能なし): 動画の添付、GIF 検索、スレッド投稿(+)、下書き / 予約投稿、DM のリアクション・編集・削除、グループ作成。

## 操作
- ホイール / PageUp・PageDown / Home・End でスクロール、F5 で更新
- ポスト入力: `Ctrl+Enter` で送信
- 行の「…」: リンクをコピー / ブラウザで開く
- 検索欄: `Enter` で検索 (入力中はサジェスト)
- 本文中の URL・#タグ・@メンションはクリック可 (@ はアプリ内のプロフィールへ)
- 左下のアカウント(スマホ幅では左上のアバター)からログアウト

## セッション
- Cookie と UA は `%LOCALAPPDATA%\NorthC\session.bin` に **DPAPI で暗号化**して保存 (同じ Windows ユーザーだけが復号可)
- 401 が返ったら再ログイン窓を出す。消したいときは `%LOCALAPPDATA%\NorthC` を削除

## ビルド
- mingw-w64: `./build_mingw.sh` / MSVC: `build.bat` (※MSVC は未検証)
- 依存: cJSON 1.7.18 (MIT, 同梱)。WebView2 は公式ヘッダーの代わりに、使う分だけの最小宣言 `src/webview2_min.h` を同梱

## 構成
`ui.c` 画面・各ビュー(ホーム/プロフィール/通知/検索/DM)とイベント / `gfx.c` フォント・GDI+描画・アイコン・テキスト折り返し / `net.c` WinHTTP とワーカースレッド・画像キャッシュ /
`login.c` WebView2 ログイン / `util.c` 補助 / `main.c` 起動

## 未確認 / 既知の制限
- 通知・検索・DM の通信は、送ってもらった HAR (レスポンスの形・POST の中身) とフロントの JS から組んだ。次は実機で未確認:
  通知の「メンション」タブ名、検索の「ユーザー」タブの結果の形、メッセージリクエスト (`requests=true`)、
  DM の過去分ページングの並び順、DM 新規作成 (`POST /api/dm/conversations {handle}`) のレスポンスの形
- 実機の Windows での動作確認はユーザー報告ベース。開発側は Linux の mingw-w64 でビルドし、Wine + 仮想ディスプレイ上でデモモードの描画を確認している。DPI 拡大時の見た目は未確認
- 403 が返る場合 (Cloudflare が WinHTTP を弾く) は、非表示の WebView2 から `fetch` する方式に変える必要がある
- 動画・GIF はサムネイル + ▶ 表示のみ (再生はしない)。アバターは画像の `avatarOriginalUrl` (jpg) を使う (GDI+ が webp を読めないため)
- アイコンは GDI+ の手描き。絵文字は GDI のフォント代替に依存 (モノクロになる場合あり)

## 利用者数の集計 (任意・同意制)
`src/config.h` の `STATS_URL` を設定したビルドでだけ有効になる。空のままなら何も送らない。
サーバーは `backend/` (Node.js + Web ダッシュボード。詳細は `backend/README.md`)。

- **初回ログイン時に同意ダイアログ**を出す (既定は「いいえ」)。同意した場合だけ、起動時に1日1回送信する。
- **送る情報**: ユーザーIDと端末ID(Windows の MachineGuid)を `SHA-256` で一方向ハッシュ化した値、アプリのバージョン。
- **送らない情報**: パスワード / Cookie / トークン / 投稿・DM の内容 / 生のID。IP アドレスはサーバーに保存しない。
- サーバーでさらに秘密鍵(pepper)で HMAC をかけて保存する。DB が漏れても元のIDには戻せない。
- **いつでもオフにできる**: 左下のアカウントメニュー(スマホ幅では左上のメニュー)の「利用者数の集計に協力する」。
  オフにするとサーバーへ削除依頼 (`/v1/forget`) を送り、以降は何も送らない。
- 設定は `%LOCALAPPDATA%\NorthC\settings.ini` の `[telemetry]` (`consent` / `last_ping` ほか)。
